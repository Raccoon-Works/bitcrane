Hosting and server logs

The site is hosted by ALL-INKL.COM – Neue Medien Münnich, owner René Münnich, Hauptstraße 68, 02742 Friedersdorf, Germany, under a data processing agreement according to Art. 28 GDPR. When you open a page, the server automatically processes details your browser sends:

  • IP address

  • page or file requested, amount of data sent and status code
  • browser and operating system
  • previously visited page (referrer), if sent

This data is used to deliver the site, run it securely and find errors. The legal basis is Art. 6 (1) (f) GDPR; the legitimate interest is a stable and secure service. The logs keep the IP address shortened, so it can no longer be traced to a person. We do not analyse the logs or combine them with other data; they are deleted once they are no longer needed for these purposes. The servers are located in Germany only.
