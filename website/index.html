    Bitcrane überträgt Dateien per SFTP, FTP, WebDAV, SMB, S3 und in die Cloud. Ordner werden überwacht, geänderte Dateien gehen von selbst hoch. Terminal und Editor sind eingebaut. Bitcrane moves files over SFTP, FTP, WebDAV, SMB, S3 and to the cloud. It watches your folders and uploads changed files on its own. A terminal and an editor come built in.

    Kurz gefragtQuick questions

    Was kostet Bitcrane?What does Bitcrane cost?
    Nichts. Bitcrane ist Open Source unter der GPL-3.0, der Quellcode liegt auf GitHub.Nothing. Bitcrane is open source under the GPL-3.0; the source code is on GitHub.
    Was heißt Beta?What does beta mean?
    SFTP, FTP, FTPS und Dropbox sind gründlich getestet. WebDAV, S3, SMB, OneDrive und Google Drive funktionieren, sind aber noch wenig erprobt. Für Google Drive brauchst du zurzeit einen eigenen Zugang aus der Google Cloud Console (Client-ID und Secret). Fehler meldest du am besten auf GitHub.SFTP, FTP, FTPS and Dropbox are thoroughly tested. WebDAV, S3, SMB, OneDrive and Google Drive work but have seen less use so far. Google Drive currently needs your own access from the Google Cloud Console (client ID and secret). Please report problems on GitHub.
    Sendet Bitcrane Daten irgendwohin?Does Bitcrane send data anywhere?
    Nur zu den Servern, die du einrichtest. Für Updates fragt es bei GitHub nach der neuesten Version. Es gibt keine Nutzungsstatistik.Only to the servers you set up. For updates it asks GitHub for the latest version. There is no usage tracking.
