    Kurz gefragtQuick questions

    Was kostet Bitcrane?What does Bitcrane cost?
    Nichts. Bitcrane ist Open Source unter der GPL-3.0, der Quellcode liegt auf GitHub.Nothing. Bitcrane is open source under the GPL-3.0; the source code is on GitHub.
    Was heißt Beta?What does beta mean?
    SFTP, FTP, FTPS und Dropbox sind gründlich getestet. WebDAV, S3 und SMB funktionieren, sind aber noch wenig erprobt. Fehler meldest du am besten auf GitHub.SFTP, FTP, FTPS and Dropbox are thoroughly tested. WebDAV, S3 and SMB work but have seen less use so far. Please report problems on GitHub.
    Sendet Bitcrane Daten irgendwohin?Does Bitcrane send data anywhere?
    Nur zu den Servern, die du einrichtest. Für Updates fragt es bei GitHub nach der neuesten Version. Es gibt keine Nutzungsstatistik.Only to the servers you set up. For updates it asks GitHub for the latest version. There is no usage tracking.
